🔒 Политика конфиденциальности

Дата вступления в силу: 10 августа 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности определяет порядок обработки персональных данных пользователей OnikaAnime.

1.2. Используя Сайт, пользователь дает согласие на обработку своих персональных данных.

2. Какие данные собираются

2.1. Сайт собирает следующие данные:

  • Email — для входа и восстановления пароля
  • Имя пользователя — для отображения в профиле
  • Аватар — для персонализации
  • Список избранного — для сохранения предпочтений
  • Комментарии — для общения
  • Время на сайте — для статистики
  • Достижения — для системы прогресса

3. Как используются данные

3.1. Данные используются для:

  • Предоставления доступа к функциям сайта
  • Персонализации контента
  • Улучшения работы сайта
  • Ведения статистики

4. Хранение данных

4.1. Данные хранятся на серверах OnikaAnime и в локальном хранилище браузера.

4.2. Срок хранения — до момента удаления аккаунта пользователя.

5. Защита данных

5.1. Сайт использует современные методы шифрования для защиты данных.

5.2. Доступ к данным имеют только авторизованные сотрудники.

6. Права пользователя

6.1. Пользователь имеет право:

  • Запросить копию своих данных
  • Изменить или удалить свои данные
  • Отозвать согласие на обработку данных

7. Использование cookies

7.1. Сайт использует cookies и localStorage для сохранения сессии и настроек пользователя.

7.2. Пользователь может отключить cookies в настройках браузера, но это может нарушить работу Сайта.

8. Передача данных третьим лицам

8.1. Сайт не передаёт персональные данные пользователей третьим лицам, кроме случаев, предусмотренных законодательством РФ.

9. Контакты

По вопросам конфиденциальности: support@onikaanime.com
